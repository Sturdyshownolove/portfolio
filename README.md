# 💼 Developer Portfolio Website

A clean, responsive, editorial-style personal portfolio website built with semantic HTML5, modern CSS (flexbox/grid/animations), and vanilla JavaScript.

## ✨ Features
- **Hero Canvas Animation:** Interactive particle/grid canvas background.
- **Embedded Interactive Demos:** Includes live demo versions of *Lab Escape* and *Pengus*.
- **Technical Skills Matrix:** Structured categories for programming languages, IT systems, and development tooling.
- **Responsive Layout:** Optimized for desktop, tablet, and mobile browsers.

## 🛠 Customization
- Open `index.html` to update your name, bio, social links, and email.
- The latest resume is linked at `Anil-Aygun-CV.pdf`.
- Custom styling can be adjusted in `style.css`.
